An index is a separate data structure that helps PostgreSQL find rows without scanning a whole table. It is a performance tool with a write and storage cost.

Start with the query

Index the columns used by frequent filters, joins and ordering. Validate the change with EXPLAIN (ANALYZE, BUFFERS), not intuition alone.

CREATE INDEX idx_orders_customer_id
ON orders (customer_id);

Trade-offs

Indexes speed reads but add work to inserts, updates and vacuuming. A small, selective index is often more useful than a wide index added “just in case.”

Key takeaways

  • Measure before and after.
  • Keep statistics fresh.
  • Prefer the smallest index that supports the access pattern.
